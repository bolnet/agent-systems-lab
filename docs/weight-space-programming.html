We repeated MIT's weight-space programming experiments

GPT-6 Astra and Opus 5.5 each wrote working game players as plain numbers, with no training and no tools. We used MIT's prompts and scoring. Our Astra runs came out close to MIT's, except Seaquest, at about half their score.

From prompt to score

The prompt

The game's rules and source code, the input and output layout, the network, how it is scored, and a small language for setting weights. All 14 prompts match MIT's byte for byte.

The reply

The model designs a controller, then writes it out as numbers. It can't run code, and the network never plays before scoring.

The build

Our reader takes the last edits block in the reply and fills in the weights. It read every statement in all six replies with no errors.

The score

1,000 games of MinAtar 1.0.15, actions sampled from the network's output, sticky actions at 0.1, and a 10,000-step limit per game.

How numbers alone can play a game

A large weight turns a tanh unit into a near on/off switch, so the network behaves like a small logic circuit. Drag the slider to see it. This is an illustration of the function, not data from a run.

With an input of 0.5, the unit outputs 0.46

  • Layer 1 computes. In Opus's Breakout network, one unit adds up numbers from the ball, trail and paddle cells to get "landing column minus paddle column", including wall bounces. The largest weight in this layer is 200.
  • Layer 2 decides. Its units are AND gates that combine a mode flag, such as "ball descending", with a direction to move.
  • The output acts. Left and right get a logit of +10 when their gate is on and -10 when it's off, so play is almost deterministic. The network uses 1,217 of its 20,486 weights, and the rest stay at 0.

Limits of these results

  • Experiments 2, 3, 4, 6, 7 and 8 were not run, so this says nothing about them.
  • ChatGPT logins can't use Astra in Codex, so we reached it through OpenRouter. MIT's prompts, instructions and effort settings stayed the same. Astra's token counts differ from MIT's, and we don't know why.
  • MIT didn't publish its reader or its full keyword list, so we rebuilt both from its stated rules. Our reader rebuilds MIT's three networks exactly, and marks MIT's four answers correctly.
  • Opus wrote this code and report while also being one of the models compared. As an outside check, MIT's networks scored 502.9, 55.2 and 54.3 on our scorer, against their 517.4, 53.1 and 53.2.

Check it yourself

This rebuilds every network from its saved reply, replays it and marks each answer again. It calls no model and writes no files. The full replay took under 5 minutes on our Mac, and --no-play skips the games.

git clone https://github.com/bolnet/context-clock
cd context-clock
pip install -r requirements-weightspace.txt
python -m context_clock.weightspace.verify_runs
